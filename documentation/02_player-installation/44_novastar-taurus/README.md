# NovaStar Taurus

The NovaStar Taurus series (TB30, TB40, TB50, TB60, and similar) are Android-based players
that drive LED displays. Digisigns manages Taurus players through the VNNOX platform: the
player binds to the Digisigns VNNOX server, then you pair it to your account using its
serial number.

Setting up a Taurus player takes three steps:

1. **[Configure the network](01_configuring-networks.md)** — bring the Taurus online over
   Ethernet or Wi-Fi using ViPlex.
2. **[Bind to the Digisigns server](02_binding-to-the-digisigns-server.md)** — point the
   player at the Digisigns server in ViPlex Express.
3. **[Pair in the Digisigns dashboard](03_pairing-in-the-digisigns-dashboard.md)** — enter
   the device serial number (SN) as the pairing code.

> [!note]
> You'll need NovaStar's **ViPlex Handy** (mobile) or **ViPlex Express** (Windows) app to
> configure the player. The default device login is user **admin** with the password
> printed on the device's SSID label.
