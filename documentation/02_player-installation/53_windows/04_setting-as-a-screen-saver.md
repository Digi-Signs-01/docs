# Setting as a screen saver

Digisigns can be installed and executed as a Screensaver

When running in screensaver mode, the Digisigns Player will exit once there is a screen touch, key pressed, or mouse move.

## Step 1 - Digisigns Installation

1. Install the Digisigns  Player App for Windows.
2. Pair your screen with your Digisigns account.
3. Go to Player's Settings and disable the option “Automatically start app when device is booting up”.

![](https://static.helpjuice.com/helpjuice_production/uploads/upload/image/23821/direct/1731419368388/installing-onsign-tv-as-a-screensaver-on-windows_1.png)

## Step 2 - Screensaver Setup

1. On your Windows device, go to the folder where Digisigns is installed. The path is usually:  
   "C:\Users\%USERPROFILE%\AppData\Local\Digisigns".

![](https://static.helpjuice.com/helpjuice_production/uploads/upload/image/23821/direct/1731419467970/screensaver-file.jpg)

2. Locate the folder and right-click on the "Digisigns Screensaver.scr” file. Select install as shown below:

![](https://static.helpjuice.com/helpjuice_production/uploads/upload/image/23821/direct/1731419488739/installing-onsign-tv-as-a-screensaver-on-windows_2.png)

3. After clicking install, configure the wait time as needed.

![](https://static.helpjuice.com/helpjuice_production/uploads/upload/image/23821/direct/1731419508039/installing-onsign-tv-as-a-screensaver-on-windows_3.png)

## Running Digisigns in Screensaver Mode from Command Line

You can also run Digisigns in screensaver mode by adding the parameter --screensaver.

This will start Digisigns in screensaver mode. Keep in mind that Digisigns will immediately end executing once a key press or mouse move is detected.
